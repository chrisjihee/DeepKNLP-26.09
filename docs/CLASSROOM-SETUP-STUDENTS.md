# 수강생 PC 준비 — [A4021] 언어지능 1일차

강사가 이 문서를 화면에 띄우고 한 줄씩 불러 주면, 각자 자기 PC의 터미널에 그대로 칩니다.
단계마다 **성공하면 보이는 것**을 적어 두었으니, 그것이 보이면 다음으로 넘어가세요.

> **강사용 한 줄** — 오전 이론(10:00~12:00) 중에 ③번까지 **백그라운드로 돌려 두게** 하면
> 오후 실습을 기다림 없이 바로 시작할 수 있습니다. ③번은 한 번 시작하면 손댈 것이 없습니다.

## 걸리는 시간 (예상)

아래는 강사 PC 기준의 **예상치**입니다. 수강생 PC에서 실측한 값이 아니고, 여러 대가 동시에
받으면 더 걸릴 수 있습니다.

| 단계 | 예상 |
|---|---|
| ① clone (약 136MB, 전송량 약 25MB) | 2~5분 |
| ③ 환경 + 1일차 모델 | 7~13분 (환경 5~10분 + 모델 2~3분) |
| **합계** | **10~18분** |

---

## ① 저장소 받기

```
git clone https://github.com/chrisjihee/DeepKNLP-26.09.git
```

**성공하면** — `Receiving objects: 100% ...` 가 끝까지 올라가고 프롬프트가 돌아옵니다.
실습 데이터까지 들어 있어 받고 나면 약 136MB(내려받는 양은 약 25MB)이므로 몇 분 걸립니다.

## ② 폴더로 들어가기

```
cd DeepKNLP-26.09
```

**성공하면** — 프롬프트에 `DeepKNLP-26.09` 가 보입니다. `ls` 를 치면 `day1`, `data`, `tools` 가 보입니다.

## ③ 환경 만들고 1일차 모델 받기

```
bash setup_classroom.sh day1
```

한 번에 세 가지를 합니다 — 파이썬 환경(`.venv`) 만들기 → **1일차 모델 2개만** 내려받기
(`klue/roberta-base`, `paust/pko-t5-base`, 합쳐서 1GB 미만) → 점검.

**성공하면** — 마지막에 이런 줄들이 지나갑니다.

```
torch 2.11.0 | cuda True | transformers ... | trl ... | peft ...
  OK  [1일차] klue/roberta-base
  OK  [1일차] paust/pko-t5-base
  없음 [2일차] skt/A.X-4.0-Light
```

- **`cuda True`** 가 핵심입니다. `False` 면 GPU를 못 쓰는 상태입니다(아래 표 참고).
- **`없음 [2일차]` 는 정상입니다.** 2일차 모델은 오전에 받지 않습니다.

## ④ 준비됐는지 다시 확인하기

```
bash setup_classroom.sh check
```

③ 끝에 이미 한 번 돌아가지만, 화면을 넘겨 버렸거나 나중에 다시 보고 싶을 때 씁니다.

**성공하면** — GPU 한 줄(RTX 4500 Ada, 24GB 정도), 패키지 버전 목록, 데이터 `OK` 줄들,
그리고 ③과 같은 모델 캐시 목록이 나옵니다.

## ⑤ 노트북 열기

```
.venv/bin/jupyter lab
```

**성공하면** — 브라우저가 저절로 열리고 왼쪽에 파일 목록이 보입니다.
`day1` 폴더를 열어 **`01_주제분류.ipynb`** 를 더블클릭합니다.

- 커널을 고르라고 하면 **`Python (DeepKNLP)`** 를 고릅니다.
- 셀은 위에서부터 `Shift+Enter` 로 차례차례 실행합니다.
- 오후 실습은 `01_주제분류` → `02_문장유사도` → `03_개체명인식` 순서입니다.

## 2일차 모델은 오후 실습이 끝난 뒤에

2일차(LLM 파인튜닝) 모델은 세 개를 합쳐 **약 24GB** 입니다(수업 기본 `skt/A.X-4.0-Light` 만 약 15GB). 8~10대가 오전에 동시에 받으면 강의실 네트워크가
느려져 1일차 실습까지 밀립니다. **1일차 오후 실습을 마친 뒤** 아래를 실행하세요.

```

```

시간이 걸리므로 켜 두고 퇴실해도 됩니다. 다음 날 아침 `bash setup_classroom.sh check` 로
`OK [2일차]` 세 줄이 보이면 준비된 것입니다.

## 자주 나오는 문제

| 증상 | 왜 | 어떻게 |
|---|---|---|
| `cuda False` 또는 `nvidia-smi` 실패 | GPU 드라이버를 못 찾음 | 조교를 부릅니다. 급하면 CPU로도 노트북은 열리지만 학습이 매우 느립니다 |
| clone 이 한참 멈춰 있음 | 여러 대가 동시에 받는 중 | 기다립니다. 5분이 넘으면 `Ctrl+C` 후 폴더를 지우고(`rm -rf DeepKNLP-26.09`) 다시 ①번 |
| `uv: command not found` / uv 설치 실패 | 설치 스크립트가 막혔거나 PATH에 없음 | `export PATH=$HOME/.local/bin:$PATH` 후 ③번을 다시 실행합니다 |
| jupyter 가 `port 8888 is already in use` | 포트가 이미 쓰이는 중 | `.venv/bin/jupyter lab --port 8889` 로 엽니다 |
| 미션 셀에서 `NotImplementedError` | **정상입니다** | 직접 채우라고 비워 둔 자리입니다. 위의 설명을 읽고 채운 뒤, 바로 아래 '확인' 셀을 실행하세요 |
| 커널 목록에 `Python (DeepKNLP)` 가 없음 | 커널 등록이 안 됨 | `.venv/bin/python -m ipykernel install --user --name deepknlp --display-name "Python (DeepKNLP)"` |

막히면 손을 들어 주세요. 조교가 자리로 갑니다.
