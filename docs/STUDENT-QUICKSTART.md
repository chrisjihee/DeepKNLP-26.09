
## 5. 미션 — 빈칸 채우기

노트북 중간에 **미션 셀**이 있습니다. 태스크마다 미션이 **셋**이고, 나머지 코드는 다 쓰여 있습니다.

- **미션 셀 ①** — 빈칸 두 곳. 모델에 **넣는 쪽**(head 만들기, 라벨 붙이기 …).
- **미션 셀 ②** — 빈칸 한 곳. 모델이 **낸 것을 받는 쪽**(숫자를 채점 가능한 문자열로 되돌리기 …).
  여기서 만든 함수가 뒤의 평가 셀에서 그대로 쓰입니다.

빈칸마다 **바로 위에 객관식 카드**가 있습니다. 보기를 고르면 **정답이면 바로**, 오답이면 **5초 뒤에** 알려 주고, 틀리면 힌트가
하나씩 열립니다. 고른 답을 `____` 에 옮겨 적으면 됩니다.

```python
# ══════════════════════════════════════════
#  미션 m-tc-1 · m-tc-2 — 분류 head 만들기와 라벨 붙이기
# ══════════════════════════════════════════
# 아래 코드에서 ____ 두 곳만 채우세요. 나머지는 그대로 두면 됩니다.

def build_model():
    return AutoModelForSequenceClassification.from_pretrained(MODEL, num_labels=____)   # m-tc-1


def encode_choice(tokenizer, rows, max_len=MAX_LEN):
    enc = tokenizer([r["input"]["text"] for r in rows], truncation=True, max_length=max_len)
    enc["labels"] = [____ for r in rows]   # m-tc-2
    return Dataset.from_dict(dict(enc))
```

**빈칸에 무엇을 넣을지는 바로 위에 있는 객관식 두 개가 물어봅니다**(§6). 거기서 고른 답을
그대로 옮겨 적으면 됩니다.

빈칸을 채우지 않고 그냥 내려가면 **'확인' 셀에서** 이렇게 멈춥니다 — 정상입니다.

```
NameError: name '____' is not defined
```

미션 셀 자체는 함수를 정의만 하므로 오류 없이 지나갑니다. 실제로 멈추는 곳은 그 아래 '확인' 셀입니다.
빈칸을 채운 뒤 '확인' 셀을 실행하면 맞게 했는지 알려 줍니다.

## 6. 정답 열기 — 노트북 안에서 객관식으로

정답은 **노트북 안에서** 봅니다. 터미널 명령은 없습니다.

1. **미션 셀 바로 위**에 있는 **객관식 셀** 두 개를 실행하면 보기 네 개가 버튼으로 나옵니다.
   하나를 고르세요. (셀 순서: 설명 → **객관식 두 개** → 미션 셀 → 확인 셀)
2. 맞으면 바로 정답과 해설이 열립니다. 틀리면 "왜 틀렸는지" 한 줄과 함께 **힌트**가 하나씩 열립니다
   (개념 → 참고 자료·웹 검색 링크 → "AI에게 이렇게 물어보세요" 예시 질문).
3. **막히면 스스로 열어 보세요.** 먼저 객관식을 풀어 보고, 그래도 모르겠으면 힌트를
   개념 → 근거자료·검색 → AI 질문 순서로 하나씩 열어 봅니다. 그래도 안 되면
   **[정답 바로 보기]** 가 있습니다 — "정말 보시겠습니까? 더 생각해 보시겠습니까?"를 두 번 확인하고
   10초를 기다리면 열립니다. 정답 코드 옆 **복사** 버튼으로 미션 셀에 붙여 넣으세요.
4. 강의 페이지(`lecture-site/index.html`)의 확인문제도 같은 방식입니다.

- 정답 파일을 따로 열 필요가 없고, 추가 패키지도 필요하지 않습니다.
- 셀을 다시 실행해도 이미 고른 답과 열어 본 힌트는 그대로 남습니다(브라우저에 저장).

## 7. 모델은 어디서 오나 — Hugging Face

우리 코드에는 모델 파일 경로가 없습니다. **저장소 주소 하나**뿐입니다.

```python
MODEL_ID = "skt/A.X-4.0-Light"
```

`from_pretrained(MODEL_ID)` 가 [Hugging Face](https://huggingface.co) 에서 내려받아
`~/.cache/huggingface/hub` 에 넣어 둡니다. **한 번 받으면 다시 받지 않습니다** —
그래서 `setup_classroom.sh models` 로 미리 받아 두면 수업 중에 기다릴 일이 없습니다.

저장소 첫 화면이 그 모델의 **모델 카드**입니다. 라이선스·크기·쓰는 법·성능이 거기 적혀 있습니다.

- 실습5 모델: **https://huggingface.co/skt/A.X-4.0-Light**

### 로그인·토큰이 필요한가

> **오늘 쓰는 모델은 전부 공개라 로그인도 토큰도 필요하지 않습니다.**
> 아침에 계정을 만들거나 토큰을 발급할 일이 없습니다. 바로 `setup_classroom.sh models` 로 가세요.

일부 저장소는 **gated** 입니다 — 만든 쪽이 약관 동의를 요구합니다(Llama 계열 등).
나중에 그런 모델을 직접 쓸 때만 세 단계가 필요합니다.

1. 모델 카드에서 **약관에 동의**합니다(승인이 바로 나는 곳도, 며칠 걸리는 곳도 있습니다).
2. 계정 Settings → Access Tokens 에서 **읽기 전용(read)** 토큰을 발급합니다.
3. 터미널에서 `hf auth login` 을 실행해 그 토큰을 한 번 넣어 둡니다.

⚠️ **토큰을 코드나 노트북에 적지 마세요.** 저장소에 올라가면 남이 내 계정으로 쓸 수 있습니다.
`hf auth login` 으로 저장하거나, 환경변수 `HF_TOKEN` 을 쓰세요.
